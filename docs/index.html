    The model

    A Fourier, uncertainty-aware generative network, trained on RICE1 for haze and thin cloud and on RICE2 for thick cloud and shadow.

    1. Global branch

      A SwinIR transformer with Fourier Units, so every patch sees the whole image’s frequency content and long-range structure.

    2. Local branch

      A TransGAN generator for fine texture: field edges, roads and roofs.

    3. Wavelet fusion

      The two branches are merged band by band in a wavelet decomposition, low frequencies from one, detail from the other.

    4. Uncertainty head

      Predicts the expected error at each pixel with a Laplace likelihood. That map weights the adversarial loss, so the model invents content only where the ground is hidden.

    Every number and image here comes from the model’s own test run, saved in the project repository: a fixed, seeded 80/20 split of RICE, predictions and uncertainty maps per image, and per-image PSNR and SSIM. The weights were trained on a GPU cluster and are not served from this page, so it shows recorded outputs rather than running the network. The uncertainty maps were saved scaled to each image, so the marking above ranks pixels within a scene, not across scenes.
